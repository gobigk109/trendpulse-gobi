# TrendPulse - Trending Stories Analysis

## Project Overview

TrendPulse is a Python-based data analysis project that collects trending stories from Hacker News, processes the data, performs analysis, and creates visualizations.

## Project Workflow

The project is divided into four main tasks:

### Task 1 - Data Collection
- Collects top trending stories from Hacker News API
- Extracts story title, score, and author
- Saves the collected data into a CSV file

### Task 2 - Data Processing
- Loads the collected CSV data
- Checks for missing values
- Checks for duplicate records
- Removes rows with missing scores
- Saves the cleaned data

### Task 3 - Data Analysis
- Finds the top trending story
- Calculates the average story score
- Sorts stories based on score
- Displays important insights from the dataset

### Task 4 - Data Visualization
- Creates charts to understand story scores
- Visualizes the distribution of scores
- Creates bar charts for trending stories

## Technologies Used
